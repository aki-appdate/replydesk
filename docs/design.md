# ReplyDesk デザイン方針

## 使う人と場面
- **担当者**：ゲーム（架空の「ほしぞらテイルズ」）のプレイヤーからのメールに、マニュアルを確かめながら一通ずつ丁寧に返す。急ぐより、間違えないことが大事。
- **SV**：相談された問い合わせを判断し、返信の質とマニュアルの穴を見直す。足りない記事を書き足すのもSVの仕事。

## 性格を表す3語
**落ち着いている・誠実・確かめられる**

## たとえ：便箋と、赤ペンの校正と、付箋
ReplyDesk の画面は「手紙を書き、送る前に赤を入れる机」として作る。ほかの2本と形を分けるため、次の道具だけを使う。
- **便箋**：問い合わせと返信は手紙として明朝体で読ませる。返信の下書きや申し送りには罫線（`.ruled`、行の高さ2remと罫線の間隔をそろえる）を引く。
- **赤ペンの校正**：送信前の3つの確認は、校正の記号で見せる（部品は `src/components/proof.tsx`）。
  1. 根拠 … マニュアルと一字一句一致した文の左に緑の ✓（`good`）と「マニュアル『記事名』と一字一句一致」。確認できない文は ✗。
  2. 言い回し … 約束してはいけない一文を赤の丸で囲み（`RedCircle`）、引き出し線と「トル」（校正で「削る」の記号）＋理由を書く（`bad`）。直すまで送信できない。
  3. 判断 … 担当者が判断してはいけない内容には「SVへ」の札（上の帯がのり代、`warn`）を貼る。担当者は送れない。
  - 色だけでなく、必ず記号（✓・✗・丸囲みとトル・SVへ）と文章で伝える。「要確認」は人が確かめたうえで送れる。「対象外」は線の印。
- **付箋**：SVの画面で、AIが書いた「マニュアルに足す記事の下書き」だけに使う（`.sticky-note`、黄色の紙 `note`、右下の角が折れている、少しだけ傾ける）。注意（`warn`）とは色と形で分ける。
- **奥付**：紹介ページの最後は、本の奥付のように作った人・分担・技術・ソースを書く。
- 使わないもの：丸い印鑑（LearnCheck の「検印」と重なる）、教科書の余白の注、✧などの飾り記号、グラデーション、影（ダイアログだけ）。

## 印
- **ロゴ**：夜空の紺の封筒を、星の金の封蝋で閉じた形（`LogoMark`）。角丸の箱に星を入れただけの形にはしない。
- **AIの印**：万年筆のペン先（`Icon name="nib"`）。AIが「下書きした」ことを表す。AIの返信案・見立て・記事の下書き・AIの種類の表示で使う。

## 色
- 紙の生成り（`canvas`・`paper`・`surface`）に、夜空の紺（`brand`）。
- 星の金（`star`）はロゴの封蝋だけ。文字には使わない。
- 赤（`bad`）は赤ペン＝止める理由にだけ使う。緑（`good`）は根拠の一致、琥珀（`warn`）はSVへ。
- 付箋の黄（`note`・`note-edge`）は記事の下書きだけ。

## 書体
- 画面の文字は Noto Sans JP。問い合わせ本文・返信文・見出し・付箋の題は Noto Serif JP（手紙らしさ）。
- 数字・時刻・IDは `tabular-nums`。ただし主役の大きな数字（SV画面の対応率）はプロポーショナルのゴシックで、明朝にしない。
- 見出しは `word-break: auto-phrase`。それでも崩れる長い見出しは、読点ごとに `inline-block` で区切る。

## 形・余白・文字の段階
- 紙（校正紙・直す前／後の返信）は角4px、画面の面は8〜10px、付箋は2px。
- CallNote より広めの余白。読む順番（問い合わせ → 返信案 → 赤 → 送信）を上から下へ。
- 見出し 22/17px（明朝）・本文 15px（手紙）/14px（画面）・補足 12px。

## 画面ごとの組み立て
- **紹介（/）**：①1枚の校正紙（届いた問い合わせ → AIの下書き → ✓と赤丸とトル → 押せない送信）②赤の入れ方の凡例（印・確かめること・印がついたら）③「よくある返信を、こう直します」：直す前の返信と ReplyDesk を通した返信を並べる（赤の理由・✓・SVへは lib の判定を実際に通して出す）④奥付。
- **受信箱（/inbox）**：危ない言い回しは、返信欄の下に赤丸とトルで出す。送信前の確認は3行の表。
- **SV（/insights）**：数字のタイルを並べない。主役の数字は1つ（24時間以内の対応率）で、ほかの数字は罫線の上の「申し送り」の文に入れて読ませる。その下に「マニュアルに足す記事の下書き」：左にマニュアルにない質問を文面のまま並べ、右に付箋の下書きを貼る。付箋の根拠は問い合わせ本文の抜き書きで見せ、付箋にふれると左の該当する問い合わせが付箋の色で光る。

## 状態
- 選択中＝左に紺の線＋薄い紺。急ぎ＝左に赤い線と「急ぎ」の文字。
- 押せない＝紙の色の地に薄い文字＋枠線（白文字にしない）、理由を文章で。
- 読み込み中＝封筒の印が明滅。下書きを書いている間は、付箋の場所が薄い黄で明滅する。空＝「ここに下書きが貼られます」と書く。

## アイコン
- インラインSVG、線の太さ1.75で統一。絵文字は使わない。

## グラフ
- 1系列は1色（紺 `brand`）。一番大きい棒だけ濃く、残りは薄い紺。棒は24px以下・先端だけ4px丸め。値は文字色で書く。各グラフに「表で見る」を付ける。
- 主役の数字は1画面に1つ。

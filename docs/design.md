# ReplyDesk デザイン方針

## 使う人と場面
- **担当者**：ゲーム（架空の「ほしぞらテイルズ」）のプレイヤーからのメールに、マニュアルを確かめながら一通ずつ丁寧に返す。急ぐより、間違えないことが大事。
- **SV**：相談された問い合わせを判断し、返信の質とマニュアルの穴を見直す。

## 性格を表す3語
**落ち着いている・誠実・確かめられる**

## 見た目の決まり
- **たとえ**：便箋と校正。問い合わせと返信は「手紙」として明朝体で読ませ、確かめる部分（根拠・言い回し・相談）は赤ペンの校正のように、はっきり印をつける。
- **色**：紙の生成り（`canvas`）に、夜空の紺（`brand`）。ゲームの世界観から、星の金（`star`）をロゴと小さな印だけに使う。
- **安全のしるし**：送信前に3つの関門を必ず見せる。
  1. 根拠 … マニュアルで確認できた文に ✓（`good`）、確認できない文に ✗（`bad`）
  2. 言い回し … 危ない言い回しがあると止まる（`bad`、該当の言葉と理由を表示）
  3. 判断 … SVに相談が必要な内容は、担当者は送れない（`warn`）
  色だけでなく、必ず記号（✓・✗・止）と文章で伝える。関門がすべて通ったときだけ送信ボタンが押せる。
- **書体**：画面の文字は Noto Sans JP。問い合わせ本文・返信文・見出しは Noto Serif JP（手紙らしさ）。数字・時刻・IDは等幅（`tabular-nums`）。
- **形**：角丸は中くらい（8〜10px）。紙の上に罫線で区切った面を置く。影は使わない（ダイアログだけ）。
- **余白**：CallNote より広め。1画面に詰め込まず、読む順番（問い合わせ → 返信案 → 確認 → 送信）を上から下へ。
- **文字の段階**：見出し 22/17px（明朝）・本文 15px（手紙）/14px（画面）・補足 12px。
- **状態**：選択中＝左に紺の線＋薄い紺。急ぎ＝左に赤い印と「急ぎ」の文字。押せない＝薄く＋理由を文章で。
- **アイコン**：インラインSVG、線の太さ1.75で統一。絵文字は使わない。

## グラフ
- 1系列は1色（紺 `brand`）。棒は24px以下・先端だけ4px丸め。値は文字色で書く。各グラフに「表で見る」を付ける。
